# Smash Burger site copy

Local static copy of the public SMASH concept page by Aleryc Digital Studio.

## Structure

- `en/index.html` — English entry page
- `css/style.css` — layout, typography, and scroll effects
- `js/` — page behavior, including the scroll synchronized hero and burger anatomy
- `assets/anatomia/pc/` and `assets/anatomia/tel/` — 133 frames each for the separated burger animation
- `assets/anatomia/pc-leggero/` and `assets/anatomia/tel-leggero/` — lighter versions of those frames
- `assets/video/` — desktop hero video and lighter version
- `assets/img/` — photos, masks, logos, and final animation frames
- `fonts/` — Bricolage Grotesque and Young Serif

Source: `https://aleryc.com/progetti/smash-burger/en/`. The public page serves these static resources; no official source repository was identified. This copy contains the client-side files and media, not server-side services.

Open `en/index.html` in a browser. If local file security limits media or animation loading, serve the folder with a local static web server and open `/en/`.
