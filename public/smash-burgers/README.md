# Brasa Norte — Smash burgers

Landing page ficticia para portafolio, ambientada en Trujillo, Perú. La carta usa soles como precios referenciales; el formulario de pedido es una demostración local y no envía información.

## Archivos

- `index.html` — contenido y estructura
- `styles.css` — diseño adaptable, ilustraciones CSS y animaciones
- `app.js` — menú, resumen de pedido de muestra, horario de Lima y animación por scroll
- `assets/` — marca y portada en SVG

El concepto toma como referencia el lenguaje editorial y la narrativa visual de una landing de hamburguesas: fondo oscuro, tipografía expresiva y capas que se separan al desplazarse. La marca, los textos, precios, ilustraciones y código de esta versión son originales; no incorpora las fotos ni los videos de la página de referencia.

Puedes abrir `index.html` directamente o servir la carpeta con cualquier servidor estático.
